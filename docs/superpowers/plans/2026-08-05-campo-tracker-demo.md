# Campo Tracker Demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a navigable, visually polished React demo of a field-personnel-tracking SaaS dashboard, using 100% mock data, to show a prospective client this week.

**Architecture:** Single-page React app (Vite) with client-side routing between Login, Dashboard, Mobile Showcase, and Grupos de Trabajo. All data comes from one static TypeScript file (`src/data/mockData.ts`); no network calls, no backend, no persistence.

**Tech Stack:** Vite, React 18, TypeScript, Tailwind CSS v4, shadcn/ui, lucide-react, react-router-dom, Recharts (used only if a chart is needed in Grupos — see Task 11).

## Global Constraints

- Spec: `docs/superpowers/specs/2026-08-05-campo-tracker-demo-design.md` — every task below implements a section of it.
- No emojis anywhere in code, UI copy, or mock data. All icons come from `lucide-react`.
- Spanish (Argentina) copy throughout the UI — this mirrors the target client's own product, not a translation exercise.
- No automated test framework. Per the spec's Testing section, this is a static visual demo with no business logic to unit-test. Each task instead ends with a manual verification step: run `npm run dev`, open the relevant route, confirm it renders with no console errors and matches the spec.
- `lat`/`lng` fields in mock data are **not real GPS coordinates** — they are pre-normalized 0-100 values used directly as percentage `left`/`top` positioning inside the map SVG container.
- Color semantics are fixed across the whole app: green = activo/completado, gray = inactivo/desconectado, amber = advertencia/GPS deshabilitado, red = alerta/SOS. Never use a different color for these states.

- [ ] **Step 2: Write the derived helpers**

Create `src/lib/derived.ts`:
```ts
import { usuarios, tareas, alertas, type UsuarioCampo, type Tarea } from '@/data/mockData';

export function getUsuarioById(id: string): UsuarioCampo | undefined {
  return usuarios.find((u) => u.id === id);
}

export function getKpis() {
  const activos = usuarios.filter((u) => u.estado === 'activo').length;
  const desconectados = usuarios.filter((u) => u.estado === 'inactivo').length;
  const gpsDeshabilitado = usuarios.filter((u) => !u.gpsHabilitado).length;
  const alertasActivas = alertas.length;
  const completadas = tareas.filter((t) => t.estado === 'completada').length;
  const objetivosPct = Math.round((completadas / tareas.length) * 100);
  return { activos, desconectados, gpsDeshabilitado, alertasActivas, objetivosPct };
}

export function getTareasPorGrupo(grupo: string | 'Todos'): Tarea[] {
  if (grupo === 'Todos') return tareas;
  return tareas.filter((t) => t.grupo === grupo);
}
```
